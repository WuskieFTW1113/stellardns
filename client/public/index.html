Use StellarDNS for this machine? first run

Right now this machine asks its usual resolver. StellarDNS can take that over: it saves the current setting first, answers from the encrypted upstream, and puts the old value back when you turn it off or run restore-dns. Keep the client running while it is in charge — if nothing is listening, nothing answers.
